## About

Quizly is an Android quiz platform built with Kotlin and Jetpack Compose,
backed by a nightly server-side quiz generation pipeline that keeps content
fresh without manual authoring.

- 🧠 AI-generated quizzes refreshed automatically
- 🎮 Gamified progression — streaks, achievements, and a daily play loop
- 🏆 Leaderboards to compete with other players
- 📱 Native Android experience built entirely in Jetpack Compose
